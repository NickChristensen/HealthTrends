# HealthTrends

HealthTrends is an iOS app and widget project for viewing active energy trends. The app handles HealthKit authorization and development tools; widgets display today's energy, historical averages, and projected totals.

## Development workflow

Track current work in the [HealthTrends Linear project](https://linear.app/finely-crafted/project/healthtrends-28bdfb3e0de2), using the shared **Tasks** team (`TODO-N` IDs) and the **Software** project label. Keep acceptance criteria, progress, blockers, and validation results in Linear. GitHub hosts code, branches, and pull requests; include the Linear task ID in PR descriptions and use `todo-<number>-<short-task-title>` branch names.

Linear commit linking is enabled. Use `Fixes TODO-N` in commit messages or PR descriptions only when all acceptance criteria are complete and required validation has passed. Use a neutral reference such as `Related to TODO-N` for incomplete work. Preserve historical GitHub issue references, and use Linear for current task tracking instead of creating duplicate GitHub Issues.
